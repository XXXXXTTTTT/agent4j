# Phase 6.1 Codebase RAG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `agent-rag` 中实现父子代码切片、JavaParser 符号索引、pgvector 向量召回、PostgreSQL GIN 词法召回、Java BM25 和三路混合检索，并用真实 pgvector 容器验证事务与隔离语义。

**Architecture:** `agent-rag` 依赖 `agent-sandbox` 的 `AstService`，但保持与 `agent-core`、`agent-web` 解耦。`CodebaseIngestionService` 只负责读取与切片，`JdbcRagStore` 负责 PostgreSQL 事务和 SQL，`HybridRagRetriever` 只负责一次请求的召回项合并与稳定排序；DataSource、Clock、EmbeddingModel 和 AstService 均由构造器注入。

**Tech Stack:** Java 21、JavaParser 3.28.2、Spring JDBC、PostgreSQL JDBC、pgvector `vector(8)`、Testcontainers `pgvector/pgvector:pg16`、JUnit 5、AssertJ。
