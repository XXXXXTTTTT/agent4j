# Agent4J CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 提供一个 Java 21 CLI，通过现有 REST/SSE API 创建、恢复和跟随工作区会话，并能用精确环境变量启动 Compose。

**Architecture:** `agent-cli` 只包含参数解析、HTTP API 客户端、SSE 事件读取、交互循环和 Compose 进程启动器；Agent 图、状态机和持久化仍由 `agent-web` 提供。CLI 将本机真实工作区映射到 Compose 的 `/agent-workspace`，不输出敏感环境变量。

**Tech Stack:** Java 21 `HttpClient`, Jackson, JUnit 5, Maven Shade Plugin, POSIX/PowerShell launcher scripts.
