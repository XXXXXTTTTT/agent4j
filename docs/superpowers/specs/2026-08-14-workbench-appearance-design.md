# Agent4J 工作台外观自定义设计

## 背景

当前工作台只有一套固定暖色深色样式，颜色、字体、圆角、密度与布局不能独立调节。用户需要稳定切换多个主题，同时保持桌面三栏结构、各栏独立滚动和移动端响应式行为。

本设计参考 QuantumNous/new-api 的公开交互结构：将外观状态拆分为预设、模式和独立视觉轴，以 DOM 数据属性驱动语义 CSS 变量，并通过侧边抽屉展示可视化选项。不会复用其品牌、组件源码、主题名称或素材。

## 目标

- 在工作台中提供可打开的“外观”设置抽屉。
- 支持深色、浅色、跟随系统三种模式。
- 支持五套 Agent4J 主题预设：石墨、纸页、松林、信号、海港。
- 支持无衬线、衬线、等宽界面字体；紧凑、标准、舒展密度；直角、柔和、圆润圆角。
- 将偏好保存到浏览器 `localStorage`，启动时严格校验后恢复。
- 切换主题时保持既有 DOM、工作流、固定壳层和可访问性契约不变。

## 非目标

- 不增加账户级或服务端同步设置。
- 不引入第三方 UI 库、CSS 框架或外部字体下载。
- 不改变模型池、会话、MCP、Skill 和执行审批的业务行为。

## 架构

新增 `appearance` 领域模块。`appearancePreferences.ts` 定义可选值、默认值和读取校验；`AppearanceProvider` 管理 React 状态，将标准化偏好写入 `document.documentElement` 的 `data-*` 属性，并持久化到单一 JSON 键；`AppearanceSettingsDialog` 只消费 Provider 暴露的读写接口。

`styles.css` 改为语义令牌驱动：表面、文字、边界、交互、状态和排版变量均由根令牌读取。模式与预设只覆盖令牌，密度和圆角独立覆盖尺寸变量，因此任意组合都不会改变组件的 DOM 结构或分栏高度约束。

## 交互

侧栏新增图标按钮“外观设置”。打开后显示右侧抽屉和遮罩层，焦点进入抽屉；关闭按钮、遮罩和 Escape 均可关闭。预设以小型色板呈现，当前项有文字与无障碍选中状态。模式、字体、密度、圆角使用语义化单选控件。底部提供“恢复默认外观”。

页面处于窄屏时，抽屉覆盖工作台内容而不改变主布局网格；抽屉内部独立滚动。桌面端应用外壳、左右栏和对话输入区继续固定在视口内。

## 验收

- 刷新页面后，用户选择的有效偏好仍生效；损坏或未知存储值回退默认值。
- 每套预设在深色和浅色模式下有可读的前景、背景、边框、焦点和状态颜色。
- 所有模式、字体、密度、圆角组合都不产生页面级纵向滚动。
- 主题抽屉可通过键盘打开、操作和关闭，选项具有明确名称与选中状态。
- 现有工作台、会话、模型池、MCP 和受治理 CLI 测试全部通过。
